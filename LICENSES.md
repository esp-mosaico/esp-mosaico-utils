# Licensing status

The ESP-Iris component is distributed under Apache-2.0; its license text is at
`ESP-Iris/components/esp_iris/LICENSE`.

The migrated ESP-Mosaico Recovery and host-tool sources did not contain a
repository-level license in their source snapshot. This migration does not
silently add or change a license grant. A maintainer must select and add the
intended repository or subtree license before publishing ESP-Mosaico Tools
`0.1.0` for third-party use.

Third-party components fetched by ESP-IDF, Python, or npm retain their own
licenses and are not relicensed by this repository.
